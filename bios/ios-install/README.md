# Original v86 iPhone installation helpers

These ARMv7 binaries are compiled from `tools/ios/guest` with macOS Command
Line Tools and local symbol-only link stubs. They contain v86 code and
ad-hoc signatures, without Apple framework implementations, firmware or keys.
They target the supported N90 iOS 6.1.3 build 10B329 runtime.

`manifest.json` binds each binary and its build inputs to SHA-256 digests.
`make app` and `make pages` verify and copy this complete set on any build
host, including Linux. Changing a build input makes that check fail until
the assets are rebuilt.

To refresh on macOS, run `make ios-install-assets-refresh`. Review the
source, binary and manifest changes together. Test apps generated by
`make ios-install-fixtures` are local build products and are not release
assets. The separately built graphics adapter remains owner supplied.
